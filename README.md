# PIKOM AI Chapter — Member Portal

Malaysia's verified AI industry, connected in one place.

## Seven Pillars

| Pillar | Description |
|--------|-------------|
| Directory | 157 member profiles searchable by capability and sector |
| Marketplace | Demand board for active AI requirements (RFPs) |
| Intelligence | Curated research from Anthropic, Stanford, McKinsey and more |
| Community | Member forums and Special Interest Groups (SIGs) |
| Talent | AI job listings and HRD Corp-certified courses |
| Policy | Malaysian AI regulatory tracker and advocacy scorecard |
| Agency Connect | Integration layer for MDEC, Meranti, MCMC, Cradle |

## Tech Stack

- **Framework**: Next.js 15 (App Router, TypeScript)
- **Database**: Supabase (Phase 2)
- **CMS**: Sanity.io (Phase 2)
- **Hosting**: Vercel (Singapore region `sin1`)

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

This project is configured for Vercel. Connect the GitHub repo to Vercel
and it will auto-deploy on every push to `main`.
